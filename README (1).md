# Órbita

Juego arcade para navegador: gira alrededor de tu planeta, cambia de sentido y esquiva la lluvia de meteoritos.
Funciona en móvil, tablet y ordenador (táctil, ratón, teclado y mando) y se puede instalar como app (PWA) y jugar sin conexión.

## Cómo jugar
- **Toca / clic / Espacio / botón A**: cambia el sentido de la órbita.
- Recoge cristales para subir de sector y gástalos en la **tienda** (naves, planetas y fondos).
- **Esc / P / Start**: pausa. **M**: silenciar.

## Instalar como app
Abre la web y usa *Instalar app* (Chrome/Edge) o *Compartir → Añadir a pantalla de inicio* (Safari en iPhone/iPad).
